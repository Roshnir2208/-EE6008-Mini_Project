# -EE6008-Mini_Project - Waste Classification on OpenMV RT1062
This project performs real-time waste classification (Cardboard, Garbage, Glass, Metal, Paper, Plastic, Trash) using models trained on the Roboflow "Garbage Classifier" dataset and deployed to the OpenMV RT1062 platform.
